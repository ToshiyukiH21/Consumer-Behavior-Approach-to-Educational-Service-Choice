# 学習塾選択における消費価値と家族内意思決定の分析

## プロジェクト概要

新潟市の中学3年生795人を対象としたアンケート調査データを用いて、学習塾の入塾目的、重視される消費価値、家庭教育方針、家族内意思決定の関係を分析した。

学習塾経営における顧客理解と、入塾目的に応じたマーケティング施策の検討を目的とする。

## 分析課題

1. 入塾目的によって、重視される消費価値は異なるのか？
2. 消費価値の普及度と特徴度には、どのような違いがあるのか？
3. 家庭教育方針は、消費価値や家族内意思決定とどのように関連するのか？

## 使用技術

- Power BI：データ可視化、クロス集計
- DAX：共起率、共起リフト、目的内カバー率の算出
- 統計分析：カイ二乗検定、ロジスティック回帰（検証結果は精査中）

## 主な分析結果

### 分析1：入塾目的と消費価値の関連

機能的価値（V1）は幅広い入塾目的で選択されていた。一方、学力補完（P2）および学習習慣形成（P4）では、体験的・情緒的価値（V2）との特徴的な共起が観察された。

### 分析2：普及度と特徴度

V1は普及度が高い一方、共起リフトはほぼ1.0であった。

V2では、性別、入塾時期、学習塾規模によって普及度と特徴度の組み合わせが異なった。

### 分析3：家庭教育方針と学習塾選択

家庭教育方針によって、社会的価値（V3）の選択率や母親の意思決定関与率に違いが観察された。

ただし、家庭教育方針と各指標の関係は単調ではなかった。

## ビジネスへの示唆

学習塾の価値訴求では、機能的価値を基本としながら、入塾目的や顧客属性に応じて体験的・情緒的価値を組み合わせることが施策仮説として考えられる。

## 分析上の注意点

本分析は横断的な観察データに基づき、因果関係を示すものではない。少人数集団の結果や統計的な群間差には追加検証が必要である。

個票データは公開せず、公開可能な集計結果と可視化を掲載する。
